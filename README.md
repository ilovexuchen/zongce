# 综测规划

适配安卓的五育素质评价规划网页。按四川大学计算机学院（软件学院、智能科学与技术学院）2025年版细则整理，只计算素质评价。

**活动、评分、目录授权和证据照片留在本机；GitHub只托管程序与公开规则资料。分数为预估，最终以学院认定为准。**

## 使用

1. 打开部署后的HTTPS网址，先在“设置”核对学年、年级、起止日期。
2. 阅读“规则与规划口径”。5处歧义已按用户提供方向复核处理，其余解释有标注。
3. 在“备份”选择手机保存目录。浏览器不支持时，使用浏览器本地模式。
4. 首页点击任一五育板块，展开细则，添加活动和多张照片；支持编辑、删除并实时重算。
5. 定期“导出完整备份”。ZIP包含所有记录和原图，可在新浏览器或手机导入。

浏览器下载不能确认已落盘，所以只提示“已发起下载”；目录/文件保存器只有写入、关闭并读回验证后才显示写入成功。

## 本机运行

安装Node.js 20或以上，在项目目录运行：

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。运行应用不需要安装npm依赖；只有浏览器自动测试需要开发依赖。

```powershell
npm test
npm install
npm run test:browser
```

浏览器测试默认尝试Windows已安装Edge，否则使用Playwright Chromium；可设置`BROWSER_PATH`指定浏览器。缺少浏览器时运行`npx playwright install chromium`。

## 部署

仓库包含GitHub Pages工作流：推送`codex/zongce-planner`后，先执行计分/备份/持久化单元测试，再仅发布`index.html`、样式、源模块、图标、PWA文件和原始规则PDF。不会发布本机照片、测试备份、现有Word文件或node_modules。

GitHub仓库`Settings → Pages → Source`选择`GitHub Actions`。首次启用或部署状态见[部署与使用说明](./部署与使用说明.md)。

## 技术结构

原生HTML/CSS/JavaScript，无运行时外部依赖；IndexedDB保存记录与照片Blob；File System Access API用于目录；标准未压缩ZIP保存完整备份；Service Worker缓存应用与手册用于离线。没有账号、业务服务器、统计代码或照片上传接口。

## 已知边界

- 目录能力和授权持久性由浏览器及安卓文件提供程序决定，不能保证永久授权。
- 浏览器数据可能被用户或系统清理，持久存储请求不能代替备份。
- 单张照片上限40MB，每条最多100张；完整备份最多20000张、约1GB，过大时会明确停止，不生成缺图“完整备份”。
- ZIP导入支持本工具导出的Store格式，不是任意压缩包解压器。
- 默认保留历史快照和旧照片以支持恢复；当前版本不自动清理历史，以免误删。空间长期增长时先导出备份，再在新目录导入。
- 安卓真机相机、系统目录选择器及浏览器重启权限需在实际设备核验；自动化模拟不冒充真机认证。
